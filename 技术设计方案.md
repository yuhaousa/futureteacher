## 1. 项目概述

EduLearn Pro 是一个面向教师群体的专业学习平台，支持课程学习、学习路径规划、社区互动和 AI 辅助教学内容生成。

### 核心功能模块

| 模块 | 描述 |
|------|------|
| 课程学习 | 浏览、报名、学习课程，支持视频/PDF 课件，模块进度跟踪 |
| 学习路径 | 管理员策划的课程序列，引导教师系统提升某一能力领域 |
| 学习社区 | 话题社区，成员可加入、发帖讨论 |
| AI 助手 | 课程推荐对话 + 管理员用 AI 生成模块教学内容 |
| 课件管理 | 管理员为每门课程的模块上传 PDF/视频，支持 AI 内容生成 |
| 管理后台 | 课程 CRUD、用户管理、路径管理、社区管理 |

**设计原则：**
- 全链路 Serverless，无需管理服务器
- 前后端分离，通过 REST API 交互
- Edge Computing，Worker 运行在离用户最近的节点
- CORS 反射请求源 Origin，支持多域名部署

### 3.4 认证状态管理

`AuthContext` 通过 `localStorage` 持久化 JWT token，每次 Axios 请求自动注入：

```js
// api/client.js
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('token');
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});
```

`Layout.jsx` 中若 `user` 为 null 则重定向 `/login`；`AdminLayout.jsx` 额外检查 `role === 'admin'`。

### 3.5 课件媒体模态播放器（CourseDetail）

学生端课程详情页的模块区域支持弹出媒体播放器：

```
点击视频缩略图 / 文件行
       ↓
媒体模态（暗色全屏叠层）
  ├── 顶部：课程标题 + ✕ 关闭
  ├── 播放区：
  │     video → <video autoPlay controls>
  │     PDF   → <iframe>
  │     右下角全屏按钮（Fullscreen API）
  ├── 当前文件名
  └── 课程材料列表（点击切换内容）
```

全屏使用 `requestFullscreen()` API，`fullscreenchange` 事件同步图标状态。

### 4.4 密码安全

```
注册/修改密码:
  password → PBKDF2(SHA-256, iterations=100000, salt=随机16字节)
  存储格式: "pbkdf2:{saltHex}:{hashHex}"

验证:
  读取 salt → 重新推导 hash → 常数时间比较（防时序攻击）
```

### 4.5 JWT

```
算法: HS256
载荷: { id, email, role, iat, exp }
有效期: 7天
密钥: wrangler secret JWT_SECRET（生产）/ "edulearn_dev_secret_2026"（开发）
```

## 5. 数据库设计

数据库：**Cloudflare D1**（基于 SQLite，Edge 分布式）

### 5.1 ER 概览

```
users ─────────┬──── courses ─────────┬──── course_modules ─────┬──── courseware_files
               │         │             │         │
               │         └── competency_tags     └── module_progress (users)
               │
               ├──── enrollments (users × courses)
               ├──── discussions (course 或 community)
               ├──── community_members (users × communities)
               ├──── communities
               ├──── learning_pathways ─── pathway_courses (× courses)
               └──── pathway_enrollments (users × pathways)
```

### 5.2 表结构详细说明

---

#### `users` — 用户表

```sql
CREATE TABLE users (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  name          TEXT NOT NULL,
  email         TEXT UNIQUE NOT NULL,
  password_hash TEXT NOT NULL,           -- pbkdf2:salt:hash
  role          TEXT NOT NULL DEFAULT 'teacher',  -- 'admin' | 'teacher' | 'student'
  avatar        TEXT,                    -- 头像 URL
  bio           TEXT,                    -- 个人简介
  created_at    DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

| 字段 | 类型 | 说明 |
|------|------|------|
| role | TEXT | admin / teacher / student，控制权限 |
| password_hash | TEXT | PBKDF2 格式，禁止明文 |

#### `courses` — 课程表

```sql
CREATE TABLE courses (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  title          TEXT NOT NULL,
  description    TEXT,
  category       TEXT,    -- 'assessment' | 'pedagogy' | 'technology' | 'wellbeing' | 'leadership' | 'curriculum' | 'special needs'
```

#### `courseware_files` — 课件文件表（迁移 0003）

```sql
CREATE TABLE courseware_files (
```

## 6. 文件存储设计

使用 **Cloudflare R2**（S3 兼容对象存储），绑定名称 `IMAGES`。

### 6.1 存储路径规范

```
R2 Bucket: futureteacher-images
│
├── courses/                    # 课程/社区封面图
│   └── {uuid}.{jpg|png|webp}
│
└── courseware/
    ├── pdf/                    # 课件 PDF
    │   └── {uuid}.pdf
    └── video/                  # 课件视频
        └── {uuid}.{mp4|webm}
```

### 6.2 访问路由

| 访问路径 | R2 Key | 说明 |
|---------|--------|------|
| `/api/images/{filename}` | `courses/{filename}` | 课程封面图 |
| `/api/files/courseware/pdf/{filename}` | `courseware/pdf/{filename}` | PDF 课件 |
| `/api/files/courseware/video/{filename}` | `courseware/video/{filename}` | 视频课件 |

响应头设置：
- 图片：`Cache-Control: public, max-age=31536000, immutable`（永久缓存）
- 课件：`Cache-Control: public, max-age=86400`（24 小时缓存）

### 6.3 上传限制

| 文件类型 | 允许格式 | 大小上限 |
|---------|---------|---------|
| 封面图 | JPEG / PNG / WebP / GIF | 5 MB |
| 课件文档 | PDF | 20 MB |
| 课件视频 | MP4 / WebM / OGG / QuickTime | 200 MB |

## 7. 认证与权限设计

### 7.1 角色体系

```
admin   — 全部权限，管理后台
teacher — 登录后台功能（个人学习），不可操作管理接口
student — 同 teacher，注册默认角色
```

### 7.2 权限中间件

```js
// 需要登录
authMiddleware: 验证 Bearer JWT → 注入 c.set('user', payload)

// 需要管理员
adminMiddleware: 读取 c.get('user') → role !== 'admin' 返回 403
```

### 7.3 初始化流程

```
首次部署 → GET /api/auth/setup-status → { needsSetup: true }
→ POST /api/auth/setup { password } → 激活 admin 账号
→ 所有 password_hash='SETUP_REQUIRED' 的教师账号设为 'teacher123'
→ 返回 JWT，进入后台
```

## 9. AI 功能设计

### 9.1 AI 对话助手（`/api/ai/chat`）

当前实现为**规则引擎 + 数据库课程数据**，无需外部 LLM API，零调用成本：

```
输入关键词分析:
  包含 "course/learn/recommend" → 查 courses 表，返回相关课程推荐
  包含 "assessment"             → 返回评估策略知识卡片
  包含 "differentiat"           → 返回差异化教学策略
  包含 "pathway/plan"           → 引导至学习路径模块
  包含 "community/colleague"    → 引导至社区模块
  其他                          → 通用欢迎引导语
```

### 9.2 AI 模块内容生成（`/api/ai/generate-module`）

管理员在 AdminCourseware 页面点击"Generate with AI"，后端根据：
- `course_title`、`module_title`、`category`、`module_index`

从内置知识库选取对应教学策略和概念，生成 Markdown 格式内容：

```
## 模块标题
### Overview      — 模块简介
### Learning Objectives — 3个学习目标
### Key Concepts  — 3个核心概念解释
### Activity 1/2  — 2个课堂活动
### Reflection Questions — 3个反思问题
### Further Reading — 推荐资源
```

**策略库覆盖领域：**
`assessment` / `pedagogy` / `technology` / `wellbeing` / `leadership` / `curriculum` / `special needs`

> 扩展方向：可替换为 Cloudflare AI Workers (`@cf/meta/llama`) 调用，实现真实 LLM 生成。

## 11. 安全设计

| 风险 | 对策 |
|------|------|
| 密码泄露 | PBKDF2-SHA256，100000 次迭代，随机 salt，常数时间比较 |
| Token 伪造 | HS256 JWT，服务端 `JWT_SECRET` wrangler secret 保护，7天过期 |
| 越权访问 | `adminMiddleware` 检查 role，前端 AdminLayout 额外拦截 |
| 注入攻击 | D1 Prepared Statements（`?` 占位符），无字符串拼接 SQL |
| 文件上传滥用 | MIME 类型白名单 + 文件大小硬限制，UUID 重命名防路径遍历 |
| CORS 跨域 | 反射 Origin 白名单策略，`credentials: true` |
| 角色提升 | 注册接口强制 `role !== 'admin'`，admin 只能通过 setup 流程创建 |
| XSS | React 自动转义，不使用 `dangerouslySetInnerHTML` |
